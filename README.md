# LA Crime Mini Project - Power BI Dashboard

## 📌 Overview
This repository contains an interactive **Power BI dashboard** developed using the **LA Crime Dataset**. The dashboard is designed to analyze crime patterns and provide meaningful insights through KPIs, charts, and interactive visualizations.

## 🚀 Features
- Interactive Power BI report with **5 dashboard tabs**
- Crime Data Analysis dashboard
- Key Performance Indicators (KPIs)
- Interactive charts and graphs
- Dynamic filtering using slicers
- Data-driven insights for better decision-making

## 🛠️ Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Microsoft Excel

## 📊 Dashboard Pages
1. Crime Data Analysis
2. Crime Trends
3. Victim Analysis
4. Location Analysis
5. Summary Dashboard

## 📈 Dashboard Highlights
- Total Crimes
- Crime Categories
- Crime Trends Over Time
- Victim Demographics
- Geographic Crime Distribution
- Interactive KPIs and Visualizations

The objective of this project is to transform raw LA crime data into an interactive Power BI dashboard that enables users to explore trends, identify patterns, and make data-driven decisions.
